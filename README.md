# Wi-Fi Deauther with ESP32
Despite the name, I used a T-A7670E for it. It's a POC I made for my school project. 
So, it scans networks... floods deauth's... capture M1+M2. Basically.

# How it works
You can control it via two ways, over serial or via Bluetooth. My preferred is Bluetooth, but you'd have to install the app.
I vibecoded the entire app, and some features in the .ino file. This is more of a POC.
